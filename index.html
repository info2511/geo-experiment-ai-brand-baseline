宠物自动喂食器：AI 推荐品牌格局实测

实验编号 GEO-PETFDR-20260924 ｜ 实测日期 2026-09-24 ｜ 数据来源：本机直连各平台 API 实测
一句话结论：同样的问句、同一天，3 个 AI 平台给出的品牌集合几乎不重叠；而「用户问『怎么办』时 AI 会不会给品牌」，取决于它有没有联网检索，而不是取决于品牌本身。

一、方法

  • 问句：37 条真实中文问句，分四类意图（选型 / 避坑 / 解决 / 求证）。
  • 平台：3 个（DeepSeek、阿里百炼（通义千问）、智谱 GLM），均为开放 API 直连。
  • 测量：对每条答复做品牌提及统计（40 条品牌词典 + 别名归一，如 PETKIT→小佩）。
  • 检索核验：用输入 token 数判定联网检索是否真的生效——检索若生效，输入必须包含网页正文，通常数千 token 起；否则只有几十。

四、三条结论

  1. 「AI 不推荐你」有两种完全不同的原因。一种是模型参数里没有你的位置——实测无检索时，解决类问句的品牌可见度是 0，「怎么办」类问题 AI 只讲方法不给品牌；另一种是检索到了却没引用。前者改不了，后者可以靠内容策略挣。
  2. AI 会自己决定要不要联网。同一批问句中，输入 token 显示有约 14% 的条目根本没触发检索，且集中在「…怎么办」类。内容只覆盖这类话题，就可能连进检索池的机会都没有。
  3. 「AI 认知」不是一份，是每个平台一份。同一天、同一批问句，平台之间的品牌集合高度不重叠，个别品牌在一处居首、在另一处一次都不出现。

五、局限（用之前必读）

  • 测的是「现状」不是「效果」。 全部结果是「AI 现在提到谁」，属竞品诊断；不是「我发布的内容有没有被引用」。两者不可混用。
  • 单次采样的频次只有头部品牌可信。 同一问句连问 5 次，头部品牌 5/5 稳定，长尾品牌 1–3/5 波动，5 次结果的交集只有 2 个品牌。低频品牌（出现 1–2 次）可能只是采样噪声。
  • 部分条目实际未检索。 阿里百炼 37 条里有 5 条的输入 token 只有 20–115（中位 5,119），其中 4 条落在「…怎么办」类。涉及分类统计时需按 token 数分层。
  • 检索源不可见。 阿里百炼与智谱都不返回检索结果的 URL ⇒「信源结构分析」这一层本次无法完成。
  • 单品类、单时点。 只有宠物自动喂食器一个品类，测于 2026-09-24 一天。平台算法与索引随时变化，结论有时效性。
  • API 层 ≠ 消费者应用层。 本实验调用的是开放 API（deepseek-flash / qwen-flash 等），与豆包、元宝、DeepSeek 网页版的产品行为可能不同，不可直接等同。
  • 品牌词典为人工维护，共 40 个品牌条目 + 别名归一。词典外的品牌会被漏计。

六、常见问题

这些数据是怎么测的？
在本地直连各平台的开放 API，用同一批 37 条中文问句逐条提问，抓取答复文本后做品牌提及统计；同时读取返回的 token 用量，核验联网检索是否真的执行。
为什么不同平台给出的品牌差这么多？
本实验只测到「结果差异」，尚未追到「信源层」去证明因果——因为两个平台都不返回检索结果的 URL。要证明「因为信源生态不同所以品牌可见度不同」，需要 URL 级数据。
这些数据能直接用于决策吗？
可以用来看格局与量级，但要遵守三条：不看单次曝光（同问句多次结果会波动）、区分「带检索」与「不带检索」两组、注意这是 2026-09-24 的单品类快照。
为什么不直接用网页版 AI 测？
开放 API 与消费者网页版的产品行为可能不同，本实验测的是 API 层。网页版通常带更强的检索与个性化，数值不可直接对照。
